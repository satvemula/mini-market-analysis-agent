# Mini Marketing Agent Analysis  

A marketing analytics dashboard for tracking and visualizing campaign performance data using Dash.  

## Overview  
This project provides an interactive dashboard for analyzing marketing KPIs, helping businesses make data-driven decisions. It processes marketing data and visualizes it in an accessible, real-time format.  

## Features  
- Data ingestion and preprocessing for marketing datasets  
- Interactive dashboards using **Dash**  
- Campaign performance metrics visualization  
- Easy integration with CSV or API-based data sources  

## Tech Stack  
- **Python**  
- **Dash**  
- **Pandas**  
- **Plotly**
